04 — Reactive Session Palette

A session is an acoustic arc, not a category

One surface. Time flows left → right. The acoustic field parameters — energy, warmth, density, organicity — shift continuously as listening context shifts. The visual is the record of the session. No cards, no categories, no presets. Where you've been and where you are now.

Everything has weight

Motion communicates state changes, not decoration. The globe breathes. Results materialise. Session shifts are like light changing in a room.

06 — Acoustic Field

One parametric system. Not six palettes.

Music is multi-dimensional. A track is jazz AND dreamlike AND folk simultaneously — a unique position in a continuous acoustic space. The Acoustic Field is a single unified renderer whose visual output is driven by coordinates, not categories.

The wrong approach: map acoustic qualities to categories → blend N pre-made renderers. The right approach: define a continuous acoustic space → drive one unified parametric system with coordinates in that space.
Every visual property — flow angle, particle count, color temperature, layer activation — is a continuous function of the same 5 dimensions. There are no categories in the renderer. Only position. "Jazz + dreamlike + folk" is a coordinate, not a recipe.
AcousticField — type definition
energy float 0→1 Physical intensity. Drives turbulence, particle speed, spiky radial bias.
warmth float 0→1 Harmonic temperature. Maps hue continuously: 230° cold blue → 35° amber.
density float 0→1 Textural complexity. Active particle count = lerp(200, 2200, density).
organicity float 0→1 Geometric ↔ organic. Blends angular-orbital flow into curl noise.
sacred float 0→1 Ritual quality. Activates mandala layer, pulls flow toward radial orbits.
bpm int Beat rate. Controls animation phase and beat pulse accumulation.
Core rendering API — two functions, one system
// ONE flow function — all params drive it simultaneously function fieldAngle(nx, ny, cx, cy, t, P) { // organicity blends angular-orbital ↔ curl noise baseAngle = angularAngle * (1 - P.organicity) + organicAngle * P.organicity; // sacred pulls flow toward radial orbits baseAngle = baseAngle * (1 - P.sacred * .7) + sacredAngle * P.sacred * .7; // energy adds turbulence turbulence = sin(nx*4 + t) * cos(ny*3.5 - t) * P.energy * 1.4; return baseAngle + turbulence; } // ONE color function — warmth drives hue continuously function acousticColor(P, alpha = 1) { hue = 230 + (35 - 230) * P.warmth + P.sacred * 15; sat = 40 + P.energy * 45 + P.sacred * 10; lit = 20 + P.density * 25 + P.sacred * 20 + P.energy * 8; return `hsla(${hue}, ${sat}%, ${lit}%, ${alpha})`; }
Emergent layers — threshold-activated, not pre-selected
Sacred Mandala
activates when sacred > 0.04
Concentric dot rings rotating counter to each other. Gold glow at center. Intensity and ring count scale linearly with the sacred param — present at 0.05, overwhelming at 0.9.

Organic Branching
activates when organicity > 0.35
Recursive branching vine system growing from multiple base points. Branch angles wobble with time and energy. Opacity scales with how far organicity is above the threshold.
drawOrganicLayer()
Ambient Wash
activates when (1−energy)×(1−density) > 0.2
Slow drifting radial color gradients. Only present when both energy and density are low — it fills the quiet space. Disappears automatically when the field becomes active.
